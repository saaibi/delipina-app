Privacidad de mapas

Delipiña utiliza Google Maps Platform para mostrar mapas y ayudar a encontrar sucursales y el origen del reparto.

Cuando buscas una dirección, Google recibe el texto de búsqueda y los datos técnicos necesarios para prestar el servicio. Cuando se muestra un mapa, Google recibe las ubicaciones representadas. Se aplica la Política de Privacidad de Google, incorporada a este aviso para esas funciones.

Las direcciones introducidas por los usuarios se usan para organizar y entregar pedidos. El identificador del lugar puede conservarse; las coordenadas obtenidas de Google se conservan temporalmente y se renuevan o retiran según las condiciones del proveedor.

El mensajero puede activar o detener el envío de su ubicación desde la aplicación. La posición disponible se muestra a las personas autorizadas para seguir la entrega. Abrir otra aplicación de navegación no activa por sí solo el envío de ubicación a Delipiña.

Para solicitar corrección de una sucursal o consultar el uso de tus datos, contacta a la administración de Delipiña mediante los canales habituales de atención.
